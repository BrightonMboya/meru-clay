# Migrations

`pg/` is the live set: Postgres, generated by drizzle-kit from
`src/lib/db/schema.ts` and applied to Supabase with `npm run db:migrate`.
Never hand-edit a generated file — change the schema and run
`npm run db:generate`. Data-only migrations (`0001_seed_courts.sql`) are
written by hand after `drizzle-kit generate --custom`.

`0001_init.sql` and `0002_coach.sql` at this level are the original SQLite/D1
schema, kept for reference only. They are not applied to anything. The
Postgres schema is a faithful port of them — see the header comment in
`src/lib/db/schema.ts` for the two places the shapes differ.
